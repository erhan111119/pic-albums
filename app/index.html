先做一次设置

这个页面需要一枚 GitHub token 才能替你上传。token 只存在这台手机的浏览器里，不会发到任何别的服务器。

怎么生成 token（点开看）
  1. 打开 GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 选 Only select repositories → 勾 pic-albums
  3. Permissions → Repository permissions → Contents: Read and write（其他都不用给）
  4. Expiration 选 90 天，Generate，复制那串 github_pat_...

用细粒度 token 只给这一个仓库的写权限，就算手机丢了别人也只能动这个相册仓库，随时可以在同一页面 Revoke。
